# 标题

给安卓做了个纸感闹钟，开源了

# 正文

最近把自己的闹钟整理开源了，叫 Paper Alarm。

浅灰底、奶油色卡片，配一点黄色。生日可以左右滑着看，响铃时用玻璃滑块关掉。

除了日常闹钟，也能记公历和农历生日。农历日期每年重新换算，不用每年手动改公历日期；也支持从通讯录读取生日、写回联系人。

离线用，不用注册，没有广告。Android 13 及以上可以安装。

GitHub 已放源码和 APK，欢迎试用，也欢迎提 PR。不同手机的后台限制不一样，第一次用记得按提示打开提醒权限。

项目：github.com/ZionHeZY/paper-alarm
